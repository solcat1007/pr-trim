# PRTrim
> Premiere Pro 缓存清理与项目优化工具

## 功能
- **缓存扫描**：自动检测 PR 媒体缓存目录，按类型统计文件数与体积
- **项目文件分析**：解析 .prproj 项目文件，检测断链（丢失）媒体文件
- **大文件扫描**：递归扫描项目文件夹，找出 >100MB 视频文件并可归档
- **一键优化**：批量清理选中缓存，自动保存保留最近 5 个
- 所有删除操作使用回收站方式，可随时恢复

## 使用方法
```bash
# 安装依赖
install.bat
# 或手动执行
pip install -r requirements.txt

# 启动
python pr_trim.py
```
依次使用四个功能区：扫描缓存 → 分析项目 → 扫描大文件 → 一键优化。
